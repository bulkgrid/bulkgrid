# Client logos

- `claude.svg` and `cursor.svg` reuse the Bulkgrid website’s client logo artwork.
- `codex.svg` and `opencode.svg` are from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons), retrieved 2026-09-10. Their MIT license is included in `LICENSE.lobe-icons`.

The docs use these local monochrome SVGs through Mintlify's tab `icon` property.
