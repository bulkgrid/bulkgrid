Bulkgrid turns websites and GitHub repositories into searchable knowledge for your applications and AI agents.

## 1. Add a source

Open [Sources](https://bulkgrid.com/dashboard/sources) in your workspace and add a website or GitHub repository. Start with a small source or a focused section, then wait for its documents to finish indexing.

Already have indexed sources? Use one of those for the next step.

## 2. Try a search

Open the dashboard **Playground**, choose **Search**, and ask a question about your source. The results contain relevant passages and their source URLs.

If no results appear, check that indexing has finished and that the source is accessible to your workspace. See [Sources](/sources) for help.

### Call the API directly

Create an API key with `search:query` in [Settings → API Keys](https://bulkgrid.com/dashboard/settings/api-keys). Workspace owners and admins can create keys. Keep your key in your backend environment.

```bash
export BULKGRID_API_KEY='bg_live_your_api_key'
```

Node.js and Python examples use the [Bulkgrid SDKs](/sdk). Set `BULKGRID_API_KEY` in your backend environment; cURL examples also use `BULKGRID_BASE_URL=https://bulkgrid.com`.

<CodeGroup>

```js Node.js
import { BulkgridClient } from '@bulkgrid/sdk';

const client = new BulkgridClient({
  apiKey: process.env.BULKGRID_API_KEY ?? '',
  baseUrl: process.env.BULKGRID_BASE_URL ?? 'https://bulkgrid.com',
});

const data = await client.index.search({
  query: 'How do I get started?',
  limit: 3,
});
console.log(data);
```

```python Python
import os
from bulkgrid import BulkgridClient

with BulkgridClient(
    api_key=os.environ["BULKGRID_API_KEY"],
    base_url=os.environ.get("BULKGRID_BASE_URL", "https://bulkgrid.com"),
) as client:
    data = client.index.search({"query": "How do I get started?", "limit": 3})
    print(data)
```

```bash cURL
curl 'https://bulkgrid.com/api/v1/index/search' \
  -H 'Content-Type: application/json' \
  -H "x-api-key: $BULKGRID_API_KEY" \
  -d '{
    "query": "How do I get started?",
    "limit": 3
  }'
```

</CodeGroup>

Replace the query with a question your source can answer. Read the passages in `results` and follow their `url` fields to the original pages.

For access settings, see [Authentication](/authentication). To process individual URLs without creating a searchable source, see [Crawl](/crawl) or [Extraction](/extraction).
